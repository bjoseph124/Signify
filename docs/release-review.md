## Scope and findings

Checked for private-key blocks, common provider token formats, credential assignments, sensitive filenames, personal email addresses, and absolute home-directory paths. No credential matches or sensitive tracked files were found. Pattern scanning cannot guarantee the absence of every possible secret.
- Existing commit metadata contains the author's name and a machine-local email address that includes a Mac hostname. This will be public with the history. No author metadata was changed. Configure a GitHub-provided private commit email for future commits if desired.
- npm's advisory audit reported zero known vulnerabilities in the pinned web dependency tree. This is not a comprehensive vulnerability assessment of all Python dependencies or model binaries.
- Webcam frames stay in the browser. The source includes no upload endpoint, analytics, external font requests, API keys, or backend. Ordinary website asset requests still reach Vercel.
- The official model's SHA-256 matches the recorded provenance. Google's linked model card identifies Apache-2.0 licensing. Added upstream MediaPipe and React/Scheduler license copies to the public assets; the owner subsequently approved the standard MIT license for Signify's original code.
- No production training dataset, third-party photographs, or alphabet-network weights are tracked. The research branch records a publisher-declared CC0 dataset for its experimental trained artifact; the raw images and downloaded candidate weights are excluded. Publisher metadata does not independently establish every source image's rights.
- Repository visibility applies to the entire repository. The research branch, its trained artifact, evaluation reports, commit metadata, and history would become public too, despite remaining separate from `main`.

No serious security or licensing blocker was identified in this review. Before publication, the owner should be comfortable exposing the existing commit identity and separate research history. The owner subsequently approved the MIT license for original code; third-party components retain their existing terms.
